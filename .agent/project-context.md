# Native test context

The maintained SES forwarder uses Node 24 and the locked dependency graph. Its existing Mocha suite mocks AWS; tests do not send mail or access an AWS account. No database, Docker or separate environment is required. Use `bin/certify-local.ps1 -Check unit` for a complete committed-archive run; `lint` is a separate static category. The v2 publisher can record approved exact-source categories under the shared Personal Ops certification policy. AWS packaging/deployment and any supported-runtime acceptance remain separate; no hosted checks are skipped without explicit workflow mappings.
